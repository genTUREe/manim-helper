02 / MOTION

From a circle to a wave

Track a point's height as it travels around a circle to draw a sine wave.

TracedPath · ValueTracker 
circle = Circle().shift(LEFT * 3)
angle = ValueTracker(0)
dot = always_redraw(
    lambda: Dot(circle.point_at_angle(angle.get_value())))
wave = TracedPath(
    lambda: np.array([
        angle.get_value() / PI - 1,
        np.sin(angle.get_value()) - 2, 0]))
self.add(circle, wave, dot)
self.play(angle.animate.set_value(
    TAU), run_time=4, rate_func=linear)
03 / GEOMETRY

The Pythagorean theorem

See how the areas of the squares on a right triangle's sides add up.

Polygon · Transform 
A, B, C = (
    np.array([-2, -1, 0]),
    np.array([-2, 1, 0]),
    np.array([1, -1, 0]))
def square_on_side(p, q, sign):
    edge = q - p
    normal = sign * np.array([-edge[1], edge[0], 0])
    return Polygon(p, q, q + normal, p + normal)
triangle = Polygon(A, B, C)
squares = VGroup(
    square_on_side(A, B, 1),
    square_on_side(A, C, -1),
    square_on_side(B, C, 1))
self.play(Create(triangle), Create(squares))

06 / CURVES

Trace a spiral

Watch a single path wind outward from the center.

ParametricFunction · Create 
import numpy as np
spiral = ParametricFunction(
    lambda t: 0.08 * t * np.array([
        np.cos(t), np.sin(t), 0]),
    t_range=[0, 8 * PI])
self.play(Create(spiral))
07 / SEQUENCES

Fibonacci finds its golden ratio

Divide each Fibonacci number by the one before it. The ratios settle toward φ ≈ 1.618.

Axes · plot_line_graph · DashedLine 
ratios = [1, 2, 3/2, 5/3,
          8/5, 13/8, 21/13, 34/21]
phi = (1 + 5**0.5) / 2
            axes = Axes(x_range=[1, 8], y_range=[1, 2])
            graph = axes.plot_line_graph(
    range(1, 9), ratios, add_vertex_dots=True)
golden_line = DashedLine(
    axes.c2p(1, phi), axes.c2p(8, phi))
self.play(Create(graph), Create(golden_line))
